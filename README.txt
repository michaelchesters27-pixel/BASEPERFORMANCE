# B.A.S.E Performance website

## Enquiry routing (Netlify)
This site uses a Netlify Form named: **baseperformance-enquiry**

To route form submissions to the correct inbox:
1. Deploy the site to Netlify.
2. Go to **Site settings → Forms → Form notifications**.
3. Add an **Email notification** to: info@tyronebusinesshub.co.uk
4. (Optional) Add Slack/Zapier/CRM notifications as needed.

Note: The client email is intentionally **not displayed** on the website.
